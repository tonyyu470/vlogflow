# VlogFlow Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement this plan inline. The user approved the design and explicitly delegated planning, implementation and publication; no further approval gates are required.

**Goal:** Ship a runnable local browser app that turns user clips and a brief into an editable approved script, independently selected subtitles, cloned narration and a downloadable MP4.
**Architecture:** A Python package serves static HTML/CSS/JS through FastAPI. SQLite persists projects, immutable approved revisions and jobs. One worker serializes model/FFmpeg work; subprocess guards bound memory and cancellation. Content-addressed intermediates make retries reusable.
**Tech Stack:** Python 3.11–3.12, FastAPI, Pydantic, SQLite, HTTPX, Pillow, NumPy, soundfile, psutil, FFmpeg; optional MLX-Audio/Qwen and faster-whisper.
**Spec:** docs/superpowers/specs/2026-10-16-vlogflow-design.md

## Global Constraints

- Work only in this independent repository on codex/vlogflow-initial. Existing private footage, recordings and models stay outside the public repository.
- Voice follows approved narration; subtitle language is independent. Never silently rewrite, truncate or speed approved speech.
- Every media reference and time range is validated. Edits invalidate dependent artifacts; stale jobs cannot publish results.
- Heavy stages run sequentially with memory/swap/process guards. Preserve the established staged MLX implementation.
- No fabricated model results in production; test substitutes are confined to tests. Report real inference separately.
- Credentials stay local and redacted. Bind loopback, restrict browser origins and serve only registered media/artifacts.
- Only source, documentation, licensed font and synthetic fixtures are published. Audit tracked files and built distributions.

## Review Focus

Check stale job races, same-name imports, malicious filenames/provider text, arbitrary file access, upload limits, cancellation during FFmpeg/HTTP/model work, interrupted caches, invalid/NaN timestamps, Chinese and long English captions, absent FFmpeg audio streams, transcript mismatch, Windows process semantics and untested GPU claims. Real hardware is Apple Silicon only. Public CI must not download large models.

### Task 1: Package, domain and durable revision store

**Files:** pyproject.toml, src/vlogflow/{__init__,domain,store,config}.py, tests/test_store.py, tests/test_domain.py.
**Interfaces:** Project dictionaries contain id, brief, language, media, scenes, revision, epoch, subtitle_mode, translations, voice and artifacts. Scene is typed with id/media_id/start/end/description/narration/ambient. Store mutations atomically increment epoch; approval writes immutable content hash. Job publication requires its captured epoch.
**Steps:** Write failing tests for out-of-range and nonfinite scenes, immutable approval, stale publication, edit invalidation and subtitle changes retaining voice cache. Implement schema/store/config and package. Run `uv run pytest tests/test_domain.py tests/test_store.py` (Expected: all pass). Commit.

### Task 2: Media, subtitles and supervised processes

**Files:** src/vlogflow/{media,captions,processes}.py, assets/font and license, tests/test_media.py, tests/test_processes.py.
**Interfaces:** probe(path) returns duration/size/has_audio; import copies into project storage with stable content identity; run_process(argv, cancellation, budget) never uses shell. Caption cues are bounded start/end plus zh/en text. render receives approved source ranges, scene WAVs and selected cues.
**Steps:** Write failing synthetic FFmpeg integration tests for mixed aspect/no audio/Unicode filenames, reference silence/clipping, source overflow, caption bounds, cancellation and resource preflight. Implement media import, frame sampling, reference preprocessing, caption PNG/SRT and H.264/AAC renderer. Run `uv run pytest tests/test_media.py tests/test_processes.py` (Expected: all pass). Commit.

### Task 3: Vision/text providers and script validation

**Files:** src/vlogflow/providers.py, tests/test_providers.py.
**Interfaces:** Provider.complete(prompt, images) -> validated JSON; analyze one clip with timestamped sampled images; compose only existing media and user facts; translate exact approved scene texts. Settings allow Ollama or OpenAI-compatible endpoint/model/key.
**Steps:** Test real HTTP serialization against a local fixture server, bounded malformed-output retries, unconfigured failure and ID/time validation. Implement adapters, connection test, analysis caching and translation. Run `uv run pytest tests/test_providers.py` (Expected: all pass). Commit.

### Task 4: Local voice models, alignment and caches

**Files:** src/vlogflow/{voice,models,alignment}.py, src/vlogflow/workers/{mlx_qwen,torch_qwen,asr}.py, tests/test_voice.py.
**Interfaces:** generate groups of approved narration using reference hash/transcript, model revision and params; guarded stages produce WAV. ASR subprocess returns timestamped words; align to approved text or fail clearly. Model installer verifies pinned files; local model path is accepted after integrity checks.
**Steps:** Test cache invalidation, raw safetensors subset integrity, grouping/word alignment, transcript mismatch and range overflow. Generalize existing staged code without private paths, add experimental official torch adapter and setup commands. Run `uv run pytest tests/test_voice.py` (Expected: all pass). Commit.

### Task 5: Jobs and local HTTP application

**Files:** src/vlogflow/{jobs,pipeline,api,cli}.py, tests/test_api.py, tests/test_pipeline.py.
**Interfaces:** project/media/script/approval/subtitle/voice/job/artifact endpoints operate through Store. One worker invokes analyze/reference/subtitles/render/audition with a captured snapshot; cancellation and epoch protect publication. UI receives settings with masked credentials and actual job phases.
**Steps:** Write failing API tests for entire synthetic workflow, upload and path inputs, restart recovery, retry/cancel, access controls and stale completion. Implement production orchestration and CLI. Run `uv run pytest tests/test_api.py tests/test_pipeline.py` (Expected: all pass). Commit.
